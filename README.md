# Android Login App Enhancement

## Overview
This project is an enhanced version of the base Android login app. It demonstrates Android UI design, activity navigation, and basic user authentication using Java and XML in Android Studio.

---

## Features Implemented
1. **Login Functionality**
   - User login implemented with hard-coded credentials (username: `admin`, password: `1234`).
   - Authentication checks user input and navigates to the Home (Landing) screen on success.

2. **Registration Page**
   - Allows new users to create an account.
   - Validates user input (username, password, confirm password).
   
3. **Forgot Password Page**
   - Enables users to retrieve or reset their password.

4. **Reset Password Page**
   - Allows updating the password after verification.

5. **Home (Landing) Screen**
   - Displays a welcome message/dashboard after successful login.

6. **Navigation**
   - Implemented using Intents to move between activities.
   - Clickable links/buttons for “Register” and “Forgot Password” on the login screen.
